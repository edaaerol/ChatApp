# 🚀 Mini Chat System

Bu proje, istemci ve sunucu arasında iletişim kurabilen basit bir terminal tabanlı sohbet sistemidir. **C dilinde** yazılmıştır ve **socket programming** kullanarak **TCP/IP** protokolüyle çalışır. Hem **Sunucu** hem de **İstemci** uygulamaları birbirine bağlanarak metin tabanlı bir sohbet deneyimi sunar. Hem eğlenceli hem de öğretici bir proje!

## 🚀 Özellikler

- **Sunucu** ve **İstemci** uygulamaları.
- Basit metin tabanlı sohbet.
- Dinamik bağlantı yönetimi.
- **TCP/IP** tabanlı haberleşme.
- **Windows** ve **Linux** sistemleriyle uyumlu.
- **Gerçek zamanlı mesajlaşma** deneyimi!

## 🛠 Teknolojiler

- **Dil**: C
- **Socket Programming** (TCP/IP)
- **Windows** ve **Linux** uyumluluğu
- **Dev-C++** veya **Visual Studio** ile derlenebilir.

## 🏗️ Kurulum

Adım adım kurulum için aşağıdaki talimatları izleyebilirsiniz:

1. **Projenizi Klonlayın**:

   GitHub'dan projeyi klonlamak için aşağıdaki komutu kullanın:

   ```bash
   git clone https://github.com/kullaniciadi/mini-chat-system.git
   ```

2. **Derleyin**:

   - **Sunucu** ve **İstemci** dosyalarını açın ve C derleyicisi (örneğin **Visual Studio** veya **Dev-C++**) ile derleyin.

3. **Sunucu Uygulamasını Çalıştırın**:

   Sunucuya bağlantıyı bekletmek için şu komutu çalıştırın:

   ```bash
   ./server.exe
   ```

4. **İstemci Uygulamasını Çalıştırın**:

   Şimdi istemciyi başlatın ve sunucuya bağlanın:

   ```bash
   ./client.exe
   ```

5. **Sohbeti Başlatın**:

   Sunucuya bağlandıktan sonra, istemci ile sohbet etmeye başlayabilirsiniz!

## 💬 Kullanım

1. **Sunucu** programı başlatıldığında **"Dinleniyor..."** mesajını göreceksiniz. Sunucu, gelen bağlantıları bekliyor.
2. **İstemci** programını başlattığınızda, sunucuya bağlanacak ve mesaj gönderebileceksiniz.
3. **Sunucu**, istemciden gelen mesajı alır ve yanıt verir.
4. **İstemci**, sunucudan gelen cevabı alır ve ekranda gösterir.

Sunucu ile iletişime geçtikçe, birbirinize mesaj gönderebilir ve gelen cevapları görebilirsiniz.

## 💡 Örnek İletişim

**Sunucu**: Dinleniyor...

**İstemci**: Merhaba Sunucu! Nasılsın?

**Sunucu**: Merhaba İstemci! Ben iyiyim, sen nasılsın?

**İstemci**: Ben de iyiyim! Hadi biraz sohbet edelim.
